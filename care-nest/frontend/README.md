# `frontend/` — Next.js front-end applications

Front-end clients consumed by the three CareNest user roles.

| Folder           | Owner       | Stack               | Status       |
| ---------------- | ----------- | ------------------- | ------------ |
| `web-buyer/`     | buyer team  | Next.js 14 (App Router) | Phase 1   |
| `web-seller/`    | seller team | Next.js 14 (App Router) | Phase 2   |
| `web-admin/`     | platform    | Next.js 14 (App Router) | Phase 3   |

Phase 0 only ships the folder. Each app will be created via
`pnpm create next-app` in its target phase per the implementation plan.
